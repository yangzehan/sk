# Lesson 1：公开工作，给予智能体广泛上下文

## 核心理念

> **对于智能体，没写下来、不公开的内容 = 不存在。**

智能体的世界完全由**文本**构成。私聊、走廊对话、限制访问的文档，**全部对智能体不可见**。

## 实践方式

### 工作区级安全边界

Anthropic 不逐文档设置权限，而是：

- 在公司层面**选定几个安全边界**
- 创建匹配每个边界的**工作区**和**文档共享设置**
- 边界内：上下文自动流向所有成员（人类 + AI）
- 边界外：保持私密

### 优势

- 减少"这个频道该公开还是私密？"的决策疲劳
- 人类和智能体都**无需猜测**信息的可见范围
- **小而清晰**的边界优于**多而模糊**的边界

### 默认公开

- 组织内新频道**默认公开**
- 决策**必须落地**到频道、文档、会议纪要
- 写作时考虑**智能体作为文档的主要消费者**

## 公开带来的红利

| 智能体能访问到 | 智能体避免做什么 |
|--------------|----------------|
| 团队会议决策 | 不会提议已被降级的任务 |
| 其他团队的产品规范 | 不会重复造轮子 |
| 大量历史文本 | **主动浮出**人类容易错过的相关信息 |

> Anthropic **重度依赖**智能体来在快节奏行业中保持信息同步。

## 文化转变的代价

默认公开需要文化转变——但**有上下文与无上下文的智能体团队表现差距太大**，无法忽视。

## 敏感场景的处理

并非所有互动都应公开：

- **团队协作场景**：使用 [[Claude Tag]] 在公开频道协作
- **个人敏感场景**：通过 @Claude Tag 发私聊，或使用现有的 claude.ai / Claude Cowork
- **私密数据**：通过**个人 MCP 连接器**访问，知道对话和共享内容保持私密

## Anthropic 的具体清单

- [ ] 选择几个安全边界，匹配工作区和文档共享设置
- [ ] 新频道默认组织内公开
- [ ] 决策必须写入频道、文档、会议纪要
- [ ] 写作时考虑智能体可发现性
- [ ] 确保 AI 拥有完成任务所需的工具和信息

> **信息是否公开、可搜索？**

如果答案为否，请回到本 Lesson 改进基础。
