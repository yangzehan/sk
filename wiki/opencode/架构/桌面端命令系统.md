## 核心抽象

### CommandProvider

`packages/app/src/context/command.tsx` (438 行)

**CommandOption 接口**：
```typescript
export interface CommandOption {
  id: string                    // 唯一标识
  title: string                 // 显示标题
  description?: string          // 描述
  category?: string             // 分类
  keybind?: KeybindConfig      // 快捷键
  slash?: string               // 斜杠命令名 (例如 "mcp", "model", "skills")
  suggested?: boolean          // 是否建议命令
  disabled?: boolean           // 是否禁用
  hidden?: boolean             // 是否隐藏
  onSelect?: (source?: "palette" | "keybind" | "slash") => void
  onHighlight?: () => (() => void) | void
}
```

**API**：
```typescript
{
  register,                 // 注册命令组
  trigger,                  // 触发命令
  keybind,                  // 获取快捷键
  show,                     // 打开命令面板
  keybinds,                 // 启用/禁用快捷键
  suspended,
  catalog,                  // 命令目录
  options,                  // 所有命令
}
```

## 斜杠命令处理

### 显示（`slashCommands` memo）

`packages/app/src/components/prompt-input.tsx:642-664`

```typescript
const slashCommands = createMemo<SlashCommand[]>(() => {
  // 1. builtin 命令（通过 command.register 注册的）
  const builtin = command.options
    .filter((opt) => !opt.disabled && !opt.id.startsWith("suggested.") && opt.slash)
    .map((opt) => ({
      id: opt.id,
      trigger: opt.slash!,
      title: opt.title,
      description: opt.description,
      keybind: opt.keybind,
      type: "builtin" as const,
    }))

  // 2. custom 命令（来自 sync.data.command，即后端 /skill/mcp/command）
  const custom = sync.data.command
    .filter((cmd) => cmd.source !== "skill")    // ← 改动后：过滤掉 skill
    .map((cmd) => ({
      id: `custom.${cmd.name}`,
      trigger: cmd.name,
      title: cmd.name,
      description: cmd.description,
      type: "custom" as const,
      source: cmd.source,
    }))

  return [...custom, ...builtin]
})
```

### 选中分发（`handleSlashSelect`）

```typescript
const handleSlashSelect = (cmd: SlashCommand | undefined) => {
  if (!cmd) return
  closePopover()
  const images = imageAttachments()

  if (cmd.type === "custom") {
    // 自定义命令：插入文本到编辑器
    const text = `/${cmd.trigger} `
    setEditorText(text)
    prompt.set([{ type: "text", content: text, start: 0, end: text.length }, ...images], text.length)
    focusEditorEnd()
    return
  }

  // 内置命令：清空编辑器并触发命令
  clearEditor()
  prompt.set([...DEFAULT_PROMPT, ...images], 0)
  command.trigger(cmd.id, "slash")
}
```

## 关键技术细节

### Cursor 定位问题

`PromptInput` 是 `contenteditable` + 复杂的 parts store：
- `reconcile`（prompt-input.tsx:790-798）只重新渲染 DOM、**不读** `store.cursor`
- DOM 的 `currentCursor()` 在 `clearEditor` 后是 `null`

**解决方案**：
```typescript
const editor = document.querySelector('[data-component="prompt-input"]') as HTMLElement
editor.focus()
const range = document.createRange()
const sel = window.getSelection()
range.selectNodeContents(editor)
range.collapse(false)
sel?.removeAllRanges()
sel?.addRange(range)
```

`data-component="prompt-input"` 属性已存在于 `prompt-input.tsx:1506`

### 动态导入
