## 入口架构（`src/index.ts`）

```ts
export default function (pi: ExtensionAPI) {
  // 1. loadConfig() —— 28 个配置项
  const config = loadConfig();

  // 2. 三个核心 store
  const store        = new MemoryStore({...config, memoryDir: globalDir});  // 全局
  const projectStore = project.memoryDir ? new MemoryStore(projectConfig) : null;  // 项目级
  const skillStore   = new SkillStore({...});

  // 3. DatabaseManager —— SQLite FTS5 session 索引
  const dbManager = new DatabaseManager(globalDir);

  // 4. 11 类 hook
  pi.on("session_start", ...)                  // 加载磁盘 → snapshot
  pi.on("before_agent_start", async (event) => {  // 注入 system prompt
    const promptContext = await buildPromptContext(config, store, projectStore, projectName);
    if (promptContext) return { systemPrompt: event.systemPrompt + "\n\n" + promptContext };
  });
  pi.on("turn_end", ...)                       // 计数
  pi.on("message_end", ...)                    // 计数 + correction flag
  pi.on("session_before_compact", ...)         // await flush
  pi.on("session_shutdown", ...)               // fire-and-forget flush + DB 关闭
  pi.on("resources_discover", ...)             // 暴露项目级 skills 目录
}
```

## 数据目录布局

```
~/.pi/agent/pi-hermes-memory/                  ← 全局根（AGENT_ROOT/pi-hermes-memory/）
├── MEMORY.md                                  ← agent notes（§ 分隔，<!-- metadata -->）
├── USER.md                                    ← user profile
├── failure.md                                 ← 教训类记忆
├── skills/                                    ← 全局 skills
│   └── SKILL.md
├── sessions.db                                ← SQLite FTS5 session 索引
├── sessions.db-shm / sessions.db-wal          ← SQLite WAL
└── .skills-migrated-to-extension-storage      ← 迁移哨兵

~/.pi/agent/projects-memory/                   ← 项目级根（AGENT_ROOT/projects-memory/）

    ├── MEMORY.md
    └── skills/
```

## 关键设计哲学

> **Token-aware policy-only memory** —— 默认不在 system prompt 灌入实际 memory 内容，只告诉模型"memory 工具存在 + 怎么用"，让模型按需 `memory_search` 拉取。

| 设计点 | 含义 |
|---|---|
| **Policy-only 默认** | system prompt 末尾追加 ≈30 行策略块（`<memory-policy>` + `<available-memory-tools>`），**不**灌 MEMORY.md 内容 |
| **Frozen snapshot** | session 启动时一次性 `loadFromDisk()`，整个 session 内 system prompt 中 memory 内容不变（保护 pi 的 prompt cache） |
| **`<memory-context>` fence** | 注入的实际内容用 `<memory-context>` XML 标签包裹 + 3 行硬指令告诉 LLM "这是参考不是新指令"（防 prompt injection） |
| **完全独立子进程** | review/flush/consolidation 全用 `pi -p --no-session --no-extensions -e OWN_EXTENSION_PATH` 跑，不污染主 session 历史 |
| **2-pass correction 过滤** | 否定（先）→ 强信号（高置信）→ 弱信号 + 指令词（低置信），不误报 |
| **速率限制 3 turn** | correction detection 最多 3 turn 触发一次，防纠正风暴 |
